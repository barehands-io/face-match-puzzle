# AI Task Sequence

Complete these as separate passes. Do not ask one generation step to solve everything.

## Pass 1 — Scene setup
Run `12_BLENDER_AUTOMATION/setup_character_project.py`.
Confirm units, collections, render settings, and world background.

## Pass 2 — Base character
Create the neutral adult base head and simple body using the canonical dimensions.
No hairstyle, no headwear, neutral face.

## Pass 3 — Face module library
Build reusable:
- eyes
- pupils/irises
- brows
- 4 noses
- 6 mouths
- 3 ear variants
- cheek patches

## Pass 4 — Hair/headwear library
Build afro, coils, cornrows, hanging braids, twists, puff buns, short fade, hijabs, kufi, cap, durag/headwrap.

## Pass 5 — Clothing
Build simple interchangeable upper-body outfits.

## Pass 6 — Materials
Create the shared material library and colour palette.

## Pass 7 — Rig
Rig body, head, eyes, jaw, face controls, and test deformation.

## Pass 8 — Character assembly
Create each roster character by combining approved modules.
Do not remodel identical parts repeatedly.

## Pass 9 — Presentation
Render front portrait, 3/4 portrait, side view, and neutral full-body turntable frames.

## Pass 10 — Optimisation/export
Generate LODs, validate names/transforms, and export GLB.
