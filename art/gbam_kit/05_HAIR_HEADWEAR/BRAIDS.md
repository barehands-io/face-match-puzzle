# Braids Specification

Visual goal:
Chunky, readable plaits that still look good on a phone.

Base diameter:
- 0.018–0.028 m

Method:
- use Bezier curves with a bevel profile
- add a repeating plait impression through geometry or normal detail
- convert to mesh only when necessary
- root follows clear scalp partings
- tip can taper 20–35%

Cornrows:
- exaggerate scalp parting slightly
- 5–10 main rows usually read better than dozens of tiny rows

Hanging braids:
- allow small length variation
- avoid perfect mirror symmetry
- optional simple beads
