# Modular Attachment System

All head modules should be built relative to the local head origin.

Required attachment groups:
- eyes
- brows
- nose
- mouth
- cheeks
- ears
- hair
- headwear
- neck/clothing

Keep replacement assets aligned to `02_STYLE_SYSTEM/ANCHORS.csv`.

Recommended custom properties:
- `gbam_part_type`
- `gbam_variant_id`
- `gbam_age_group`
- `gbam_fit_head = HEAD_V1`
- `gbam_lod`

Do not permanently join swappable modules until the export optimisation stage.
