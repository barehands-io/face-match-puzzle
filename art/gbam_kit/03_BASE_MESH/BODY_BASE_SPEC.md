# Body Base Specification

The body is intentionally secondary to the face.

Canonical adult:
- height: 1.60 m
- head-to-body visual ratio: about 4.2 heads tall
- shoulder width: 0.38–0.42 m
- torso: short and soft
- hands: simplified mitten-like base with separated thumb and optional fingers
- feet: rounded and slightly oversized

Child:
- height: 1.25 m
- about 3.4 heads tall
- shorter limbs
- larger head ratio
- softer torso

Toddler:
- height: 0.95 m
- about 3 heads tall
- wide stance
- very simplified hands/feet

Default modelling pose:
- relaxed A-pose
- palms slightly inward
- feet shoulder-width apart
