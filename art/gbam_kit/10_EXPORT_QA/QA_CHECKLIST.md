# QA Checklist

## Visual
- [ ] Reads as GBAM style at thumbnail size
- [ ] Large eyes and cheek accents present
- [ ] Nose/mouth remain simple and graphic
- [ ] Hair silhouette is clear
- [ ] No accidental photorealism
- [ ] No logos or copied brand graphics

## Geometry
- [ ] Correct head dimensions
- [ ] Clean normals
- [ ] No z-fighting
- [ ] No visible holes
- [ ] Modifiers applied only when appropriate
- [ ] No unnecessary hidden geometry

## Rig
- [ ] Eyes rotate correctly
- [ ] Blink works
- [ ] Smile works
- [ ] Mouth opens
- [ ] Head turns without clothing/hijab clipping
- [ ] Braids/headwear follow the head

## Export
- [ ] Applied transforms
- [ ] Correct scale
- [ ] Textures load
- [ ] GLB opens successfully
- [ ] LOD naming correct
