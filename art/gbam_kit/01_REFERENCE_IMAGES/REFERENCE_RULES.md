# Reference Rules

Use the OWN_STYLE_PRIMARY images as shape-language and mood references.

Priority:
1. silhouette and proportions
2. eye/cheek/nose/mouth language
3. chunky hair/headwear construction
4. matte colour blocking
5. warm expression

Do not trace a single 2D frame into a literal 3D copy.
The 3D version should translate the design language consistently across many new characters.

Commercial/original toy photographs are intentionally NOT included in this AI handoff package.
That reduces the chance of reproducing identifiable commercial artwork.
