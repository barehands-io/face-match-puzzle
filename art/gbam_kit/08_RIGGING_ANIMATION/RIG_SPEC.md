# Rig Specification

Body:
- root
- pelvis
- spine 1–3
- neck
- head
- clavicles
- upper/lower arms
- hands
- upper/lower legs
- feet
- optional finger simplification

Face:
- eye aim L/R
- jaw control
- optional brow controls
- shape keys for major expressions

Hair/headwear:
- parent rigid pieces to head
- longer braids may use 2–4 simple bones per hanging cluster
- avoid full cloth/hair simulation for default gameplay

Default pose:
Relaxed A-pose.

Rig should be compatible with game export.
Keep controller bones separate from deformation bones.
